## 2. 15 Non-Negotiable Technical Rules (Distilled from HyperFrames & GSAP Skills)
1. **Standalone Root Contract**: Top-level `index.html` places `<div id="root" data-composition-id="main" data-width="1920" data-height="1080" data-duration="60">` directly inside `<body>` with **no** `<template>` wrapper, and styles `#root` with `width: 100%; height: 100%` (never hardcoded pixel dimensions on `#root`).
2. **One Paused GSAP Timeline**: Build a single deterministic `const tl = gsap.timeline({ paused: true })` and assign `window.__timelines["main"] = tl` only after all scene tweens are registered.
3. **Never Animate `.clip` Lifecycle**: `.clip` elements with `data-start` and `data-duration` are managed by HyperFrames (`visibility: hidden/visible`). Never tween `autoAlpha`, `opacity`, `visibility`, or `display` on `.clip` elements; animate inner `.scene-stage` children instead.
4. **Zero CSS/GSAP Transform Conflicts**: Never declare CSS `transform: translate(...)` on an element that GSAP animates with `x`, `y`, `scale`, or `rotation` (`gsap_css_transform_conflict`). Use Flexbox/Grid centering and `gsap.fromTo()`.
5. **Local `@font-face` Only**: Every named `font-family` (`Plus Jakarta Sans`, `JetBrains Mono`, `Instrument Serif`) must have an in-file `@font-face` pointing to local `.woff2` files in `assets/fonts/` (`font_family_without_font_face`).
6. **Zero Runtime Network Dependencies**: Vendor `gsap.min.js` and `CustomEase.min.js` locally in `assets/vendor/`; never load CDN scripts or external Google Fonts at render time.
7. **Deterministic Seeded PRNG**: Replace all `Math.random()`, `Date.now()`, and `performance.now()` with a deterministic `mulberry32(1337)` generator driven solely by timeline progress.
8. **Hardware-Accelerated Transform Aliases**: Animate only `x`, `y`, `scale`, `scaleX`, `scaleY`, `rotation`, `rotationX`, `rotationY`, and `opacity` — never layout-thrashing `top`, `left`, `width`, or `height`.
9. **Audio Element Hygiene**: Every `<audio>` element must carry a unique `id`, `data-start`, `data-duration`, and `data-track-index`, and must **never** include a `crossorigin` attribute (`media_crossorigin_breaks_preview`).
10. **Stacked Multi-Tween Safety**: When chaining multiple `.fromTo()` tweens on the same target and property across beats, pass `immediateRender: false` on every subsequent tween so earlier states are never clobbered.
11. **WCAG AA Contrast Compliance**: Maintain ≥ 4.5:1 contrast for body copy and ≥ 3.0:1 for large display type (`#F5F5F4` primary text, `#A8A29E` secondary text, `#34D399` emerald, `#FB7185` rose on `#050505` / `#0E0E10` obsidian surfaces).
12. **Safe-Zone & Overflow Discipline**: Keep all critical typography and HUD cards inside a `96px` horizontal / `64px` vertical safe zone (`1728×952`), marking intentional background bleed elements with `data-layout-allow-overflow` or `data-layout-ignore`.
13. **Live HTML UI over Flat Captures**: Rebuild the 5 hero FlowAgent OS UI surfaces as crisp vector DOM + SVG components (Z-axis Hero Cascade, Gate 1 OCR Extractor, Gate 2 U-Bot Waveform & Tokenomist HUD, Gate 4 Arbitrage Race, and Gate 3 OFAC Sanctions Interlock), backed by 4K glass-framed product plates.
14. **Pre-Calculated Layout Coordinates**: Compute cursor paths, SVG `strokeDashoffset` lengths, and particle positions once during setup—never call `getBoundingClientRect()` inside a tween callback.
15. **Verification Gate Before Delivery**: Pass `npx hyperframes check` (0 lint errors, 0 runtime errors, 0 layout/contrast errors) and visually inspect exported frame snapshots across all 8 scenes before final delivery encode.
