Limitations & mitigation

รู้ข้อจำกัดก่อน
จึงออกแบบการควบคุมได้ถูกจุด

สิ่งที่ต้องพิสูจน์และเตรียมให้พร้อมก่อนนำไปใช้กับเงินจริง

ข้อจำกัด / ความเสี่ยง แนวทางที่เสนอ
AI อ่านข้อมูลผิด ตรวจ schema และยอดเงิน; ขอให้คนทบทวนเมื่อข้อมูลกำกวมหรือผู้รับไม่ชัดเจน
Screening ไม่ครอบคลุม อัปเดตฐานข้อมูล แยก match / no match / unavailable และส่งรายการไม่ชัดเจนให้ตรวจเพิ่ม
API หรือ network ขัดข้อง แสดงสถานะ degraded; เสียงใช้ text fallback ได้ แต่การคัดกรองสำคัญล้มเหลวต้องหยุดจ่าย
FX, token และ off-ramp แสดง all-in cost, quote expiry และสภาพคล่อง; ไม่ถือว่า stablecoin ขจัดความเสี่ยงทั้งหมด
สิทธิ์และข้อกำกับดูแล ใช้ role-based approval, audit trail และทบทวนข้อกำหนดตามประเทศก่อนเปิดใช้งานจริง
Non-custodial ไม่ได้ทำให้พ้นข้อกำหนดทางกฎหมายโดยอัตโนมัติ 10 / 11
